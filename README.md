# Portfolio

Personal portfolio built with React and Vite. English content, a profile carousel, a detailed PrimaVera case study, work experience, education and a printable CV preview.

## Local development

```bash
npm ci
npm run dev
```

## Verification

```bash
npm run lint
npm run check
npm run build
npm run preview
```

## Publishing

Follow [the GitHub Pages guide](docs/publikacja-github-pages.md). The prepared workflow builds and publishes on pushes to `main` once GitHub Pages is enabled.

Local interview notes in `docs/rekrutacja/` are excluded from Git. Update public content in `src/data/portfolioData.js`. See [photo replacement instructions](docs/integracja-karty-profilu.md).
